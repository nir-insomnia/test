# עריכת התוכן באתר

כל מה שמופיע באתר נמצא כאן, בתיקייה `src/content`. אפשר לערוך ישירות ב‑GitHub:
פותחים קובץ, לוחצים על עיפרון, משנים, ושומרים (`Commit changes`).
השינוי מגיע לאתר אוטומטית.

## מה איפה

| מה רוצים לשנות | הקובץ |
| --- | --- |
| שם בית הספר, המשפט בתחתית, פריטי התפריט | `site.ts` |
| טלפון, אימייל, כתובת, שם רכז/ת המגמה, מה מודפס במפה | `site.ts` (חלק `contact`) |
| כותרות ופסקאות בעמוד הבית | `site.ts` (חלק `home`) |
| כיתות, נושאים, יח״ל | `curriculum.ts` |
| פרויקטים של תלמידים | `projects.ts` |
| פוסטים בבלוג | תיקיית `posts` — קובץ `.md` אחד לכל פוסט |

## תמונות

מעלים קובץ לתחתית התיקייה `public/images`:

- `public/images/projects/` — תמונות לכרטיסי פרויקט
- `public/images/blog/` — תמונות לפוסטים

ואז כותבים באתר את הנתיב, בלי `public`:

```
image: "/images/projects/ecotrack.jpg"
```

## פוסט חדש בבלוג

1. יוצרים קובץ חדש ב‑`src/content/posts` עם שם באותיות לטיניות, למשל `open-day.md`.
2. מעתיקים לתוכו את הפתיח של אחד הקבצים הקיימים, ומשנים.
3. הגוף נכתב ב‑Markdown: `## כותרת`, `**מודגש**`, `- פריט רשימה`, `![תיאור](/images/blog/פתח.jpg)`.

הפוסט נכנס לבלוג לפי התאריך שכתבתם בפתיח — החדש בראש.

## כללי ברזל

- לא מוחקים שורה שבה פסיקים או סוגריים מסובכים — משנים רק את הטקסט שבתוך המרכאות.
- שורה שנשארה ריקה `""` מוצגת באתר כ"יעודכן כאן", ולא נעלמת.
- אחרי כל שינוי כדאי לרענן את התצוגה כדי לראות את התוצאה.
