המדריך הזה עצמו נכתב בדיוק כמו כל פוסט אחר — אז אפשר להשתמש בו כהעתק.

## 1. קובץ חדש

ב‑GitHub נכנסים ל‑`src/content/posts`, לוחצים **Add file → Create new file**,
ושמים שם באותיות לטיניות: `open-day.md`.

## 2. הפתיח

ארבע השורות הראשונות הן "תגי זיהוי". משנים רק מה שבין המרכאות:

```
---
title: "יום פתוח למגמה"
date: 2026-11-12
description: "הצצה קצרה למה שיקרה."
image: ""
tags: [אירוע]
---
```

- `date` קובע את הסדר בבלוג — החדש בראש.
- `image` ריק כמו כאן. אם תעלו תמונה ל‑`public/images/blog`, תכתבו
  `/images/blog/open-day.jpg`.
- `draft: true` שומר את הפוסט לעצמכם עד שמוחקים את השורה.

## 3. הטקסט

מתחת לפתיח כותבים חופשי:

- `## כותרת משנה`
- `**מודגש**` ו‑`*נטוי*`
- `-` לכל פריט ברשימה
- `1.` למספור
- `![תיאור](/images/blog/open-day.jpg)` לתמונה בגוף הפוסט
- `[למידע נוסף](https://example.com)` לקישור

## 4. שמירה

לוחצים **Commit changes** — ושינוי מגיע לאתר. רעננו את דף הבלוג כדי לראות.
