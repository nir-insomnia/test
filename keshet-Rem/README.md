# Keshet Ram CS Hub

Build a modern, minimalist Hebrew (RTL) website for the Computer Science track at 'קשת ראם' school (בית ספר קשת ראם - מגמת מדעי המחשב). Use the attached logo and its color palette: fresh lively green, olive green, warm amber/orange, and crisp clean backgrounds with sleek typography (e.g. Heebo/Assistant).

Implement a scroll-based experience where each section/screen highlights a core area with a bold title, concise description, rich visual/video placeholder, and a button to view the full detailed page or modal:
1. מסך פתיחה (Hero): Welcome to the Computer Science track, modern tech animations/visuals, school logo, and primary call to action.
2. אודות המגמה (About): Mission, advantages of studying computer science, achievements, learning environment and community.
3. תוכנית לימודים (Curriculum): Interactive breakdown across grade levels (י', י"א, י"ב) covering programming, algorithms, web development, cyber/AI, and matriculation units (5/10 יח"ל).
4. פרויקטי תלמידים (Student Projects): Showcase gallery of student works with project cards, tech stack tags, screenshots, and live demo/details view.
5. צור קשר ומיקום (Contact & Location): Contact form, track coordinator details, and an interactive school map view.

Include a fixed/sticky navigation bar with the school logo, smooth scroll navigation, and full mobile responsiveness.
